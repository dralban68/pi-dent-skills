# pi-dent-skills

Generic development skills and commands for pi: writing specs, docs, skills and agent briefs,
testing, repository setup, and searching docs with qmd.

```sh
pi install npm:pi-dent-skills
```

pi loads the skills under `skills/`. With [pi-dent-agent](https://www.npmjs.com/package/pi-dent-agent),
the package can instead be configured as the `dx` plugin, which adds the `commands/` and the
always-on `context.md`.
